# 🎬 MovieFlix

A modern and responsive **Movie Discovery Web Application** built using **HTML, CSS, and JavaScript**. MovieFlix integrates with the **TMDB (The Movie Database) API** to provide real-time movie information, official trailers, IMDb links, streaming providers, and a personalized favorites list.

Whether you're searching for the latest blockbuster or exploring classic films, MovieFlix delivers a clean, interactive, and user-friendly experience.

---

## 🌐 Live Demo

🔗 [Website live demo](https://debprakash-roy.github.io/movieflix/)

---

## ✨ Features

- 🔍 Search movies in real time
- 🎬 Browse trending and popular movies
- 📖 View detailed movie information
- ▶️ Watch official YouTube trailers
- ⭐ Open movie IMDb pages
- 📺 Check streaming providers
- ❤️ Save favorite movies using Local Storage
- 🌙 Dark & Light Mode
- 📱 Fully Responsive Design
- ⚡ Fast and Lightweight User Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/debprakash-roy/movieflix.git
```

### Navigate to the Project Folder

```bash
cd movieflix
```

### Run the Application

Open **index.html** directly in your browser

**OR**

Run using **Live Server** in Visual Studio Code.
